# 素材清單與 MVP 範圍

## MVP 需要的內容素材

| 素材 | 來源／製作方式 | 用途 |
|---|---|---|
| 情境分類 | 團隊自行定義 | 日常、工作、旅行、社交 |
| 語氣分類 | 團隊自行定義 | 自然、正式、禮貌、輕鬆 |
| 程度說明 | 參考 CEFR 後自行白話化 | 協助使用者自評 |
| 示範中文句 | 團隊自行撰寫 | 原型展示與測試 |
| 示範英文結果 | 人工校對的 AI 草稿 | 原型展示、品質基準 |
| 單字與句型解析 | AI 產生後人工抽查 | 學習內容 |
| 圖示 | 開源圖示庫或自行設計 | 介面操作提示 |
| 發音 | 合法 TTS 服務 | P1 發音播放 |

## 第一版範圍（做）

- 三種英文程度及白話說明。
- 四種預設情境與四種預設語氣。
- 中文輸入與結果產生。
- 基礎、自然、精準三種英文版本。
- 依程度調整的單字、片語與句型解析。
- 收藏一個選定版本至個人句子庫。
- 句子庫搜尋與基本篩選。
- 中翻英或填空複習。
- 手機優先的六個主要畫面。

## 第一版範圍（不做）

- 完整英文能力檢定或正式分級測驗。
- 真人教師即時批改。
- 社群、排行榜與公開分享牆。
- 多人共同句子庫。
- 方言、專業術語與法律、醫療等高風險翻譯保證。
- 即時語音通話與自由對話角色扮演。
- 自動訂閱付費與商業化方案。

## 內容與資料原則

- 示範句由團隊自行撰寫，避免直接複製教材或第三方內容。
- 使用者輸入預設為私人內容，不公開給其他使用者。
- 不以使用者輸入建立公開語料庫。
- 原型須清楚標示 AI 結果可能需要依實際溝通情境調整。

## 主要風險與處理

| 風險 | 第一版處理方式 |
|---|---|
| AI 改變原意 | 同時顯示原始中文，提供「語意不符」回報 |
| 結果不自然 | 建立人工校對的示範案例作為品質基準 |
| 難度判定不準 | 允許使用者切換版本與快速調整程度 |
| 私人資訊被輸入 | 提醒避免輸入敏感資料，預設不公開內容 |
| 選項太多造成負擔 | 首頁只保留情境、語氣與一個主要送出按鈕 |
