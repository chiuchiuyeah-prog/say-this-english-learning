# 功能規格表

優先度定義：P0 為 MVP 必做、P1 為下一階段、P2 為有餘裕再做。

| 功能 | 使用者可以…… | 主要規則／狀態 | 優先度 |
|---|---|---|---|
| 程度設定 | 選擇入門、中階或進階 | 預設帶入每次產生結果；可隨時修改 | P0 |
| 中文輸入 | 輸入真正想說的一段話 | 必填；第一版限制合理字數 | P0 |
| 情境選擇 | 選擇日常、工作、旅行或社交 | 必選一項；預設為日常 | P0 |
| 語氣選擇 | 選擇自然、正式、禮貌或輕鬆 | 必選一項；預設為自然 | P0 |
| 推薦說法 | 查看最符合程度的英文 | 系統依程度、情境與語氣推薦 | P0 |
| 多版本比較 | 切換基礎、自然與精準版本 | 三版本需保留相同核心語意 | P0 |
| 學習解析 | 查看單字、片語、句型與語氣 | 解析深度依程度調整 | P0 |
| 句子收藏 | 收藏選定版本 | 同時保存中文、情境、語氣與解析 | P0 |
| 句子庫 | 查看、搜尋及篩選收藏內容 | 可依關鍵字、情境及程度篩選 | P0 |
| 基礎複習 | 進行中翻英或填空題 | 答錯內容重新排入待複習 | P0 |
| 發音播放 | 聆聽英文句子 | 使用合法 TTS，不儲存第三方音檔 | P1 |
| 跟讀練習 | 錄音並比較文字辨識結果 | 第一版只判斷漏字與明顯錯字 | P1 |
| 自動間隔複習 | 依答題紀錄安排日期 | 熟悉度隨作答結果更新 | P1 |
| 自訂情境 | 新增個人常用情境 | 不影響既有預設分類 | P2 |
| 分享學習卡 | 匯出不含私人中文內容的卡片 | 分享前由使用者確認內容 | P2 |

## 非功能性需求

- 手機畫面優先，主要操作可單手完成。
- 結果頁先突出推薦句，其他內容採漸進展開。
- 產生失敗時保留使用者輸入，不要求重新輸入。
- 不將使用者輸入公開展示或用於其他使用者的內容。
- AI 結果需標示為學習建議，使用者可回報不自然或語意錯誤。
