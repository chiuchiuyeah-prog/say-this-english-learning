# User Story

## US-01：設定英文程度

> 身為英文學習者，我想要設定自己的英文程度，以便系統提供不會太簡單或太困難的說法與解析。

### 驗收條件

- 使用者可選擇入門、中階或進階。
- 每個程度都有白話說明，不只顯示 CEFR 代號。
- 設定完成後會成為預設程度，之後仍可修改。

## US-02：輸入真正想說的話

> 身為在真實生活中需要使用英文的人，我想要輸入自己想說的中文，以便學習符合當下需求的英文。

### 驗收條件

- 使用者可輸入一段中文。
- 中文不得為空白，過長時會提示縮短內容。
- 使用者可選擇日常、工作、旅行或社交情境。
- 使用者可選擇自然、正式、禮貌或輕鬆語氣。

## US-03：取得適合程度的說法

> 身為英文學習者，我想要先看到最符合自己程度的推薦說法，以便知道目前最適合學哪一句。

### 驗收條件

- 系統優先顯示一個推薦版本。
- 使用者可以切換基礎版、自然版與精準版。
- 三個版本應保留原本意思，不可為追求難度而改變語意。
- 系統要簡短說明各版本適合的使用時機。

## US-04：理解英文用法

> 身為想真正學會表達的使用者，我想要查看單字、片語、句型與語氣解析，以便了解英文為什麼這樣說。

### 驗收條件

- 解析內容依使用者程度調整深度。
- 清楚標示重點單字、片語及句型。
- 說明不能只重複中文翻譯，必須補充使用情境或語氣差異。

## US-05：收藏個人句子

> 身為經常忘記查過內容的使用者，我想要收藏自己選定的英文句子，以便日後再次使用與複習。

### 驗收條件

- 使用者可選擇三個版本中的任一版本收藏。
- 收藏內容保留原始中文、英文、情境、語氣與解析。
- 使用者可在句子庫依情境搜尋或篩選。

## US-06：複習收藏內容

> 身為想把句子真正學起來的使用者，我想要複習以前收藏的內容，以便把查過的英文轉化成自己會使用的表達。

### 驗收條件

- 系統能從已收藏句子產生中翻英、填空或重新排列練習。
- 作答後立即顯示答案與解析。
- 錯誤的題目會再次排入待複習清單。
